Salesforce Integration & APIs Q&A

August 2026  ·  Original notes based on Salesforce developer documentation

Notes on connecting Salesforce to the outside world: choosing between REST and Bulk APIs, platform events, Salesforce Connect, and secure authentication for callouts.

1.When should Bulk API be used instead of the standard REST API?

Bulk API is optimized for very large data volumes processed asynchronously — bulk loads, exports, or updates of thousands of records — while REST API suits smaller, synchronous, real-time operations where an immediate response is needed.

2.What is the practical difference between Bulk API and Bulk API 2.0?

Bulk API 2.0 simplifies the workflow by removing the need to manually manage batches — you submit data and let Salesforce handle batching internally — reducing the client-side complexity that the original Bulk API required.

3.What problem do platform events solve compared to polling for changes?

Platform events let external systems and Salesforce automation subscribe to near-real-time notifications of business events, avoiding the latency and wasted requests of a system repeatedly polling Salesforce to check for changes.

4.Why would an integration use Salesforce Connect instead of importing external data into Salesforce objects?

Salesforce Connect surfaces external data as virtual objects in real time without copying and syncing it into Salesforce storage — useful when the external system is the source of truth and duplicating the data would create staleness or storage cost.

5.Why is the Client Credentials Flow considered easier for server-to-server API authentication than other OAuth flows?

It skips user-interactive login steps entirely, authenticating as a pre-configured integration user — appropriate for trusted backend-to-backend integrations where no human is present to complete a login prompt.

6.Why is a named credential preferred over hardcoding endpoint URLs and auth details in Apex?

Named credentials centralize endpoint and authentication configuration outside the code, so credentials can be rotated or the target environment changed without modifying and redeploying Apex — separating configuration from logic.

Sources: Salesforce Developers documentation (REST API, Bulk API, Platform Events, Salesforce Connect guides). These are original notes and summaries, not reproduced source material.
