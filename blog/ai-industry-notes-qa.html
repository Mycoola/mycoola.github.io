AI Industry Notes Q&A

August 2026  ·  Original notes from a mix of industry articles

Notes on the current wave of AI industry coverage: concerns about "vibe coding," agentic AI showing up in enterprise software, the AI Agent SDK pattern, and how ethics and terminology fit into the bigger picture.

1.What is the concern behind the "vibe coding" criticism?

The worry is that developers who rely entirely on AI-generated code without understanding it lose the underlying skills needed to debug, review, or extend that code independently — producing output that works today but leaves the developer unable to maintain it tomorrow.

2.How does Salesforce's CoAct-1 represent a shift from earlier "AI assistant" patterns?

Rather than only suggesting UI clicks or text, CoAct-1 is described as writing and executing its own code to accomplish tasks — a shift from an assistant guiding a human's actions to an agent performing the actions itself.

3.What is a "headless" product architecture, and why would Salesforce position one around AI?

Headless architecture separates the underlying data/logic layer from any specific front-end UI. For an AI-oriented product, that separation lets an agent interact directly with business logic and data, without requiring a traditional browser-based UI as an intermediary.

4.What does an Agent SDK provide that a chatbot API alone doesn't?

An Agent SDK gives developers building blocks for tool use, memory, planning, and permission boundaries around a model — the scaffolding needed to build a custom autonomous agent, rather than just a single request/response chat interface.

5.Why are engineers building their own "harnesses" around agent SDKs?

A harness wraps an SDK with project-specific guardrails — logging, approval steps, sandboxing — that the raw SDK doesn't provide out of the box, letting a team control exactly how much autonomy an agent has within their own systems.

6.What is the core distinction between generative AI and predictive AI?

Predictive AI estimates an outcome from existing patterns — a probability, a classification, a forecast. Generative AI produces new content — text, images, or code — modeled on the patterns it learned, rather than just labeling or scoring existing input.

7.Why do organizations like UNESCO focus on AI ethics rather than leaving it to individual companies?

AI systems can affect rights, employment, and safety across borders and industries, so a shared ethical framework aims to set baseline expectations (fairness, transparency, accountability) that apply regardless of which company built a given system.

8.What kinds of scenarios tend to appear in AI ethics case studies?

Common cases include biased decision-making in hiring or lending algorithms, surveillance overreach, autonomous systems making high-stakes decisions without human oversight, and unclear accountability when an AI system causes harm — situations where the technology's capability outpaces existing governance.
