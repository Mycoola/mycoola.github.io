Salesforce Mobile Development Q&A

August 2026  ·  Original notes based on Salesforce Mobile SDK documentation

Notes on building for Salesforce on mobile: the Salesforce mobile app itself, custom native/hybrid apps via Mobile SDK, and offline data access with SmartStore.

1.What is the difference between using the standard Salesforce mobile app and building a custom app with Mobile SDK?

The standard app gives immediate, configurable access to an org's data via pages and layouts. Mobile SDK is for building fully custom native or hybrid apps with bespoke UI and behavior beyond what the standard app's configuration options support.

2.Why does offline access matter enough to warrant a dedicated SmartStore component?

Field-based users (sales reps, technicians) often lose connectivity. SmartStore caches data locally so the app remains usable offline, syncing changes back to Salesforce once connectivity returns, rather than the app simply failing without a network connection.

3.What is a "soup" in the context of SmartStore, and why the unusual terminology?

A soup is SmartStore's term for a named local data store (similar to a table), holding structured JSON documents with defined indexes — the term is specific to the SDK's API but the concept maps to a familiar local database table.

4.Why does mobile push notification setup require registering with both Salesforce and the device OS vendor?

Delivering a push notification requires the OS vendor's push service (Apple/Google) to route the message to the device, and Salesforce to originate and target the notification — both halves of the pipeline need proper registration and configuration to work end-to-end.

5.What should be considered before adding SmartStore to an existing Android or iOS app rather than starting a new Mobile SDK project?

Retrofitting offline storage into an app not designed for it requires reconciling existing data flow and state management with SmartStore's local-first model — a bigger structural change than adding offline support from the start of a new project.
